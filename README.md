# Distributed Computing Web Application

Вебзастосунок для асинхронного виконання трудомістких обчислень (розв'язання СЛАР) із балансуванням навантаження та чергою задач.

## Архітектура системи
- **Reverse Proxy / Load Balancer:** Nginx (порт 443 HTTPS, балансування між application-серверами)
- **Application Servers:** 2+ інстанси API (прийом задач, валідація, перевірка статусу)
- **Task Queue & Cache:** Redis (збереження стану, прогресу та черги задач)
- **Worker Nodes:** Обчислювальні процеси (ітераційний метод Якобі/Зейделя)
- **Database:** PostgreSQL (користувачі, історія та результати виконання)

## Структура гілок (Git Flow)
- `main` — стабільні релізи з тегами версій (`v0.1`, `v1.0`).
- `dev` — основна гілка інтеграції.
- `feature/TASK-ID-description` — розробка окремих модулів.
- `hotfix/TASK-ID-description` — термінові виправлення для main.
